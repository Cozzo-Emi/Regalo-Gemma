# Regalo Gemma Sofía

Aplicación web para reservar regalos del baby shower de Gemma Sofía. Cada invitado reserva con su nombre y la reserva queda bloqueada al instante.

**Demo:** https://regalos-gemma-sofia.netlify.app/

## Tecnologías

- React + Vite
- Tailwind CSS
- Firebase Realtime Database
- Netlify Functions

La administración está protegida por un PIN validado en el servidor.

## Desarrollo local

```bash
npm install
npm run dev
